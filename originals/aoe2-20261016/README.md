# OpenSamguk original art masters — 2026-10-16

Built-in image generation source masters and art-direction concepts, preserved byte-for-byte. These are original generated assets, not extracted third-party game graphics. The folder name describes an art-direction reference, not affiliation or asset provenance from another game.

- concepts/: approved paired tactical and strategic art-direction illustrations and exact prompts.
- units/v1/: four infantry/archer SW/NW poses in one transparent master, prompt, measurements and limitations.
- terrain-v1/: five selected flat ground masters, exact generation history, alpha/geometry measurements and checksums. Rejected atlas image attempts are excluded; their prompt history remains documented.

These are NOT engine-ready exports. Alpha cleanup, exact projection, anchor placement, material-ramp palette mapping, target-scale readability, adjacent seams and actual game/browser validation remain pending. No approved material-ramp palette has been applied. No application source, workflow or deployed assets change in this handoff.

Only validated deployment exports should later be copied to the application repository. Keep these masters unchanged. See each folder's README and manifests for measured limitations rather than treating prompt requirements as achieved results.
