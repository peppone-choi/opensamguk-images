# OpenSamguk unit masters v1

Original generated source art, not a production atlas. Built-in image generation only; no paid API credentials used. Master PNG preserved unmodified at 1254 × 1254 with real alpha transparency.

Layout: equal 627 × 627 cells. Top row shield/spear infantry, bottom row archer; left SW/front, right NW/rear. All bounds and approximate foot anchors are in manifest.json. Full generation prompt is in prompt.txt.

Visual inspection passed for complete separated figures and intended viewing directions. The master contains very faint alpha specks outside silhouettes, detectable at alpha 1–7. Full alpha bounds must not be used to infer tight unit crops. Suggested integration scale/anchors are unvalidated. No cropped, scaled, recolored, cleaned, or engine-ready files have been produced. Do not claim playthrough validation from these assets.
