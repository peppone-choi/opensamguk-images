## 네 가지 검수 축

오픈삼국은 승인된 절제된 AOE2풍 재질감과 중국 전략·전술 화면의 시각 방향을 유지한다. 아래 원칙은 생성 결과를 승인하는 기준이며, 생성 프롬프트를 잘 작성했다는 이유만으로 검수를 생략하지 않는다.

1. **밀도와 표시 크기**
   - 기준 줌의 실제 화면에서 병사·건물·자연물의 상대 크기와 디테일 밀도를 통일한다.
   - 큰 물체를 만들 때 작은 에셋을 임의 확대하지 않는다. 같은 밀도를 유지하도록 필요한 디테일과 작업 해상도를 확보한다.
   - EP13의 원본 1칸 = 화면 2픽셀은 참고 제작자의 규칙이다. 오픈삼국의 배율을 2×로 확정하는 근거가 아니다.
   - 출처: [EP13 0:39](https://www.youtube.com/watch?v=wyiw2JrUaCY&t=39s), [1:04–1:19](https://www.youtube.com/watch?v=wyiw2JrUaCY&t=64s).

2. **기준 팔레트와 재질별 램프**
   - 실제 게임 화면에 함께 놓인 기준 에셋을 보고 기본색과 재질별 명도 램프를 정한다. AI가 제안한 색과 램프는 사람이 승인한 뒤 사용한다.
   - 전역 최근접색 치환을 금지한다. 재질 마스크를 구분하고 같은 재질 램프 안에서 명도 순서를 보존하며 보정한다.
   - 최종 검사에는 승인 팔레트 밖 색, 재질 혼입, 대비 손실을 포함한다. 필요한 예외는 추가 이유와 승인 근거를 기록한다.
   - 시작 기본색 16–32개는 검토 범위이다. 최종 팔레트와 램프는 아직 확정되지 않았다. 영상의 물체당 4–5색을 모든 오픈삼국 에셋의 의무값으로 적용하지 않는다.
   - 출처: [EP14 0:25–0:43](https://www.youtube.com/watch?v=m3d_QXPKM4A&t=25s), [1:02–1:26](https://www.youtube.com/watch?v=m3d_QXPKM4A&t=62s).

3. **역할별 경계와 가독성**
   - 전투·조작 대상이 자연물과 배경보다 명확하게 읽히도록 역할별 경계 강도를 정한다. 모든 에셋에 동일한 검은 외곽선을 적용하지 않는다.
   - 내부 재질선은 외부 실루엣보다 절제한다. 눈·창끝 등 의미 있는 어두운 디테일을 외곽선과 혼동하지 않는다.
   - 윤곽 수정은 알파/투명 경계를 기준으로 한다. 어두운 색 전체를 삭제하거나 재칠하는 방식은 금지한다.
   - 단단한 실루엣과 승인된 부드러운 그림자·효과의 알파 규칙은 분리한다. 픽셀 두께와 허용 반투명 범위는 기준 에셋 승인 때 정한다.
   - 출처: [EP16 0:16–0:47](https://www.youtube.com/watch?v=fhcFrswuG58&t=16s), [1:04–1:24](https://www.youtube.com/watch?v=fhcFrswuG58&t=64s).

4. **고정 광원과 방향별 명암**
   - 기준 화면에서 승인한 광원 방향과 그림자 방향을 모든 에셋에 공유한다.
   - 명암이 칠해진 최종 이미지를 좌우 반전하거나 회전하여 방향별 에셋을 만들 때는 광원이 함께 뒤집히지 않도록 재명암한다. 프레임마다 같은 기준을 유지한다.
   - 광원 쪽 밝기와 그림자 방향을 검사하고 여러 에셋을 합친 화면에서 조명이 하나처럼 보이는지 사람이 확인한다.
   - EP17의 왼쪽 위 광원은 참고 사례다. 오픈삼국의 확정 방향은 승인 기준 화면을 따른다.
   - 출처: [EP17 0:22–0:48](https://www.youtube.com/watch?v=7BsE2JWxUpE&t=22s), [0:48–0:56](https://www.youtube.com/watch?v=7BsE2JWxUpE&t=48s).

**권장 작업 순서:** 기준 화면/에셋 승인 → 밀도·색·경계·광원 기준 명세 → 생성 → 배경/알파 정리 → 재질별 램프 보정 → 경계 및 명암 교정 → 수치 검사 → 실제 표시 크기와 방향별 애니메이션 합성 검수 → 사람 승인. 이 세부 순서는 오픈삼국 적용안이며 원 영상의 전문을 그대로 옮긴 것이 아니다.

**아직 확정하지 않은 수치·정책:**
- 최종 기본색 목록/HEX, 정확한 색 수, 재질별 램프 및 램프 단계 수
- 기준 줌, 에셋별 작업/출력 해상도와 표시 배율, 디테일 밀도 허용 오차
- 재질감 보존을 위한 최종 에셋별 색 수와 예외 정책
- 역할별 윤곽색·두께, 접지선/내부선 기준, 반투명 가장자리와 효과의 허용 범위
- 광원 방향, 그림자색·길이·불투명도, 명도 검사의 계산식과 허용 오차

이 값들은 현재 가이드만으로 승인된 것으로 취급하지 않는다. 작은 대표 화면과 재질/방향별 시험 에셋으로 비교한 뒤 결정한다.

## 현재 원본의 적용 상태

[현재 아트 원본과 검증 기록](../README.md)은 수정하지 않은 생성 마스터이다. 일부 프롬프트에 왼쪽 위 광원이나 목표 크기가 쓰였더라도 결과가 기준을 충족했다는 검증이나 최종 정책 승인을 뜻하지 않는다. 실제 팔레트/재질 램프 매핑, 알파 정리, 목표 크기 검수, 방향별 조명 및 게임 내 연결부 검증은 아직 완료되지 않았다. 이 문서는 새 에셋이나 기존 마스터를 배포 가능 상태로 승격하지 않는다.
