## 높이 선택 규칙

N/E/S/W 네 꼭짓점은 이웃 타일과 공유한다. 한 타일의 최소 높이를 base로 빼면 각 꼭짓점은 0 또는 1이다. 비트 0..3을 N/E/S/W에 대응시켜 mask를 선택한다. 15는 평지 mask 0을 base+1에 배치하는 것과 같으므로 중복 제작하지 않는다.

- 평지 1, 한 꼭짓점 상승 4, 인접 두 꼭짓점 상승 4, 세 꼭짓점 상승 4, 마주 보는 두 꼭짓점 상승 2 = 15.
- 기본 점: N(128,32), E(256,96), S(128,160), W(0,96). 올라간 점은 Y에서 32를 뺀다.
- 앵커 (128,96). base 높이마다 화면 Y를 32px 위로 옮긴다. 32px은 화면 규격이며 실제 고도(m) 주장이 아니다.
- 내부는 네 모서리와 평균 높이의 중심을 잇는 삼각형 4개. 안장 모양도 동일한 규칙을 쓴다.
- 평지 그림을 변형해 경사 그림을 만들지 않는다. 각 mask는 AI가 별도로 그린 그림이다.
- 절벽은 공유면의 연속성을 의도적으로 끊는 별도 경계다. 현재 옆면은 수평 상·하단을 가진 32px 세그먼트 두 방향이며 여러 단을 쌓을 수 있다.

물은 수평이다. 같은 mask의 서로 다른 육지 재질은 연속된 월드 좌표의 가중치로 섞어 재질 경계를 연결한다. `preview_iso2d_integration.py`는 이 렌더러 규약을 검증하는 합성 예시이며 새로운 AI 원본 또는 게임 렌더러 구현이 아니다. 수면으로 전환되는 영역에서는 경사 수면이 생기지 않도록 검사한다.

## 제작·재현

Python은 sprite-gen 가상환경을 쓴다: `/Users/apple/.claude/skills/sprite-gen/.venv/bin/python`.

1. `raw/`의 생성 원본과 `prompts/`의 프롬프트, `guides/`의 기하 가이드를 보존한다. AI 재생성은 비결정적이지만 저장된 원본에서의 추출은 결정적이다.
2. `prepare_iso2d_tiles.py <sheet> <out> --material <name> --bleed`로 육지를 추출한다. 최종 선택은 plain-15-fine, mountain-15, desert-15, plateau-15, hill-15, basin-v2-15 시트다.
3. `prepare_iso2d_objects.py`로 물·건물·부대·프롭·옆면을 추출한다. 물 시트는 AI가 세로 배치를 변경하여 셀 안의 알파 bbox에서 4.5% 여유 폭을 자른다. 육지 경사에는 이 경로를 적용하지 않는다. 건물은 빈 행을 찾아 그룹을 나누며 취락의 여러 집을 한 그룹으로 보존한다.
4. 추출한 후보를 `curation-input/{terrain,objects,skirts}`에 모은다. 셀 규격이 달라 세 run으로 구분한다.
5. sprite-gen `unpack_atlas_run.py --pngs-dir … --out-dir curation/<group>` → `export_curated_pngs.py --run-dir …` → `curated/`. 최종 108개는 에이전트가 조립·시각 검토한 선택이다. 사람의 최종 승인이라고 표현하지 않는다.
6. `export_iso2d_assets.py`가 curated PNG만 복사하고 manifest를 작성한다. `--check`는 curated/배포 바이트, 후보/curated 픽셀, 수량, 앵커 규격, 타일 알파 모양을 검사한다.

원본 명세를 벗어난 사각형 등을 경사 모양으로 잘라 통과시키지 않도록 8px 바깥 윤곽 한계를 검사한다. 내부 누락은 실패한다. 극히 좁은 경계만 기존 RGB를 최대 축당 2px 안에서 복사할 수 있으나 최종 육지 90개와 수면 3개는 보충 0px이다. 육지 시트 전체가 검사를 통과해야 후보 파일을 쓴다.

## 검증과 비교

- `test_iso2d_geometry.py`: 내부 누락, 빈 에셋, 사각형/잘못된 경사 거부, 원본 RGB 보존, 3D 깊이 가림 회귀검사.
- `preview_iso2d_tiles.py`: 각 육지 재질의 평지·언덕·분지·능선·안장 8×8 장면. 30개 장면에서 내부 불투명 누락 0.
- 수면 3종 8×8, 평지/강/산/구릉 혼합 8×8, 오브젝트 배치, 2단 절벽 장면을 별도 보존한다.
- `iso3d-vs-iso2d.png`: opensamguk dfec1516의 실제 glTF 19종을 CPU 깊이 버퍼로 투영해 AI 그림과 비교한다. glTF의 선형 정점색을 sRGB로 변환했다. 게임 엔진 조명·톤매핑 스크린샷은 아니다.
- 팔레트는 같은 기준 커밋의 build_iso3d_assets.py를 사용했다. 물·육지는 같은 저채도 계열이며, 오브젝트는 AI의 재질과 음영 때문에 조명 없는 3D 정점색보다 어둡다.

초기 plain-flat-pilot, plain-flat-v2, plain-ramps, plain-ramps-v2, plain-15, plain-15-v2, plain-15-bleed, basin-15 원본은 탐색/반려 이력이다. plain-ramps-v2는 최종 미세 질감 참조로도 쓰였다. 이 파일들을 배포용으로 선택하지 않는다.

## 실제 지도와 남은 범위

현재 han-tiles.json에는 지형 분류만 있고 지도 전체 꼭짓점 고도는 없다. 768×669 래스터를 기존 3D 규약과 같이 4로 묶은 192×167 격자를 명세에 기록한다. 이번 높이 QA는 명시적인 합성 높이 배열이며 실제 한나라 지형 복원을 의미하지 않는다.

기준 커밋의 전략 지물은 PASS 3곳이며 공용 관문 에셋을 제공한다. 수역 자료의 riverBarriers/traversalEdges는 비어 있고 항로 후보는 항구·상륙지 검토 근거 부족으로 차단되어 있다. 나루·항구·다리를 확정 설치 목록으로 만들지 않았다.

한 타일 내부 2단 급경사, 오버행, 기울어진 절벽 상단 연결부, 전 방향 강둑 전용 스프라이트, 별도 국가색 마스크는 제공하지 않는다. 게임 연결 시 높이 자료, 지형/재질 선택, 프롭 배치와 가림, 국가 UI 표시를 구현해야 한다. 정적인 에셋 세트의 완료와 실제 지도 렌더링의 완료를 구분한다.
