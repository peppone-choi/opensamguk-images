2. 확정된 규격 (사용자 결정 2026-09-08)
타일 단위: 지형 래스터 768×669 를 4×4 로 묶어 192×167 타일. 51만 칸을 그대로 깔 수 없어서다. 한 칸이 지도상 약 12km 로 縣 사이 질감이 살고, 3만 2천 인스턴스라 브라우저가 감당한다.
타일 규격: 256×128 다이아몬드(2:1 아이소). "지형 타일은 큼지막하게" 지시의 수치화다.
화풍: 픽셀 아트가 아니다. 손으로 그린 듯한 반사실 전략 게임 아트. 한대 중국 역사물. Concept A(ADR-LITE-049) 팔레트 — 황토·이끼녹·슬레이트회·먼지빛 청동. 채도를 낮게 둬야 국가색 깃발과 부대 색이 지도 위에서 읽힌다.
생성 방식: AI 이미지 생성(사용자 선택). 절차적 빌더가 아니다.
3. 반드시 지킬 규칙 — 지형 타일에 테두리를 넣지 마라
사용자가 롤러코스터 타이쿤을 기준으로 명시했다: 같은 높이의 인접 타일은 이음매 없이 이어지고, 흙벽(측면)은 높이가 바뀌는 곳·물가·맵 가장자리에만 나타난다. 타일 자체가 테두리선이나 사방 측면을 들고 있으면 안 된다.

3D 트랙에서 이걸로 이미 한 번 틀렸다 — 타일을 닫힌 상자로 구웠더니 깔았을 때 격자마다 검은 선이 생겼다. 지금은 윗면 한 장 + 별도 skirt 로 고쳤다. 2D 도 같은 계약이다:

다이아몬드 윗면의 가장자리 색과 높이가 네 변 모두에서 이어져야 한다.
흙벽은 별도 스프라이트(terrain/skirt)로 뽑고 렌더러가 단차에만 세운다.
산봉우리·강둑처럼 솟은 것은 윗면 위에 얹는 별도 프롭이다. 타일에 굽지 마라.
4. 검수 방법 — 낱개로 보지 마라 (BLOCKING)
3D 에서 삼각형 감김이 전부 뒤집혀 윗면이 아래를 향한 버그가 있었는데, 낱개 미리보기에서는 옆면이 보여서 멀쩡해 보였고 8×8 로 깔아 보고서야 지면이 통째로 사라진 걸 발견했다.

2D 도 같다. 낱개 타일 컨택트시트만 보고 통과시키지 마라:

같은 타일을 8×8 로 깔아 렌더한다. 격자 선·색 띠·밝기 계단이 보이면 실패다.
평지·강·산·구릉을 섞어서 깔아 경계가 자연스러운지 본다.

6. 이미 끝난 3D 트랙 (커밋 dfec1516, 브랜치 work/opensamguk/iso3d-assets)
빌더: tools/assets/build_iso3d_assets.py + tools/assets/gltf.py(표준 라이브러리 glTF 라이터)
산출물: web/game/public/models/iso3d/ — glTF 21개, 97KB, 최대 152 삼각형
규약: 결정론적이라 --check 로 드리프트를 막는다. 타일은 XZ 평면 1×1, Y 가 위. 아이소 다이아몬드는 카메라가 만든다(모양을 메시에 구우면 카메라 각도 바꿀 때 다 다시 구워야 함). 정점 색만 쓰고 텍스처 없음. 국가색은 런타임이 baseColorFactor 로 곱한다.
매니페스트: web/game/public/models/iso3d/manifest.json — 지형 목록·건물 단계·병종 표가 여기 있다.
2D 는 3D 를 대체하는 게 아니라 짝이다. 사용자는 둘 다 요청했고(2D 아이소 + 3D), 같은 지도의 두 렌더 모드가 된다. 그래서 팔레트·타일 단위·이음매 계약이 같아야 한다.

7. 파이프라인 (sprite-gen)
인터프리터는 반드시 스킬 venv 다. 전역 python3 는 쓰지 않는다:

/Users/apple/.claude/skills/sprite-gen/.venv/bin/python <script> ...
지형 타일은 애니메이션 행이 아니라 정지 세트다. 그래서 캐릭터용 base-lock/행 파이프라인이 아니라 이 경로를 쓴다:

시트 생성 — scripts/generate_sprite_image.py 로 타일 여러 장이 한 줄에 놓인 시트를 뽑는다. 배경은 크로마 키(식물이 녹색이므로 마젠타 #FF00FF).
셀 분할 — scripts/slice_sheet_cells.py(다중 도형 시트 → 셀별 컷) 또는 scripts/unpack_atlas_run.py --pngs-dir(낱장 폴더 반입).
큐레이션 — sprite-gen curation --run-dir <run> 으로 골라내고 다듬는다.
내보내기 — scripts/export_curated_pngs.py → <run-dir>/curated/. 설치는 curated/ 에서 한다. frames/ 에서 복사하지 마라 — 사람이 고친 픽셀이 조용히 빠진다.
시안 프롬프트 초안이 /tmp/claude-501/isoassets/pilot.txt 에 있었다(휘발성). 요지는 §2 화풍 + §3 이음매 규칙 + 마젠타 배경 + 「텍스트·라벨·격자선·UI·그림자 없음」이다.

8. 산출물을 어디에 둘 것인가
3D 는 절차 생성이고 제3자 파생이 아니라 opensamguk 저장소에 직접 넣었다 (web/game/public/models/, 브랜드 에셋과 같은 선례).

2D 는 AI 생성이라 다르다 — 비결정론적이라 --check 로 못 막는다. 메모리 규약상 opensamguk-images 저장소를 정본으로 두고 태그로 고정한 뒤, opensamguk 에는 export 만 복제한다 (web/game/public/ 아래). UI 아이콘·빈 상태 일러스트가 이미 그 경로를 밟았다.
