# 도시 상태 아이콘

도시 아이콘 우상단에 겹쳐 표시하는 15×15 픽셀 상태 배지와 10×10 수도 별의 정본이다.
모든 자산은 `tools/assets/build_status_icons.py`가 입력 이미지 없이 절차적으로 생성한다.

| 코드 | 의미 | 실루엣 |
| ---: | --- | --- |
| 1 | 풍작 | 곡물단 |
| 2 | 호황 | 쌓인 금화 |
| 3 | 혹한 | 눈송이 |
| 4 | 역병 | 독기 방울과 십자 |
| 5 | 지진 | 갈라진 대지 |
| 6 | 태풍 | 소용돌이 |
| 7 | 홍수 | 파도 |
| 8 | 흉년 | 시든 이삭 |
| 9 | 황건적 출현 | 불타는 황색 두건 |
| 32 | 화계·선동 | 불꽃 |
| 34 | 탈취 | 묶은 자루 |
| 43 | 출병 | 창끝 |
| — | 수도 | 금색 별 |

색을 보지 못해도 상태를 구분할 수 있도록 모든 배지는 서로 다른 알파 실루엣을 사용한다.
웹 런타임에서는 확대·축소 보간 없이 원본 픽셀 크기 또는 정수 배율로만 표시한다.
