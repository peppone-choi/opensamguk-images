# 도시 상태 아이콘

도시 아이콘 우상단에 겹쳐 표시하는 24×24 픽셀 상태 배지와 16×16 수도 별의 정본이다.
모든 자산은 ImageGen으로 만든 정본 시트를 `tools/assets/build_status_icons.py`가
셀별로 분리하고 배경 제거·팔레트 제한·1x/2x 축소해 생성한다.

| 코드 | 의미 | 실루엣 |
| ---: | --- | --- |
| 1 | 풍작 | 곡물단 |
| 2 | 호황 | 쌓인 금화 |
| 3 | 혹한 | 눈송이 |
| 4 | 역병 | 독기 방울과 십자 |
| 5 | 지진 | 갈라진 대지 |
| 6 | 태풍 | 소용돌이 |
| 7 | 홍수 | 파도 |
| 8 | 흉년 | 시든 이삭 |
| 9 | 민란 | 부러진 관아 명패·횃불·농기구 |
| 32 | 화계·선동 | 불꽃 |
| 34 | 탈취 | 묶은 자루 |
| 43 | 출병 | 창끝 |
| — | 수도 | 금색 별 |

색을 보지 못해도 상태를 구분할 수 있도록 모든 배지는 서로 다른 알파 실루엣을 사용한다.
웹 런타임에서는 `1x` 원본과 최근접 보간으로 만든 `2x` 파생본을 DPR에 맞춰 선택한다.
지도 위 배지만으로 의미를 외우게 하지 않고, 선택 패널의 상태명과 툴팁을 함께 제공한다.
