# 도시 상태 아이콘

지도에서 성 건물 좌상단에 겹쳐 표시하는 상태 배지·수도 별과, 황제 거처 표식의 정본이다.
황제 특별 NPC 이름 앞에는 같은 원화에서 별도 축소·클린업한 `imperial-npc.png`를 쓴다.
모든 자산은 ImageGen 정본 시트(`assets/status-icons/source/`)를
`tools/assets/build_status_icons.py`가 셀별로 분리하고 배경 제거·팔레트 제한·배율별
독립 축소해 생성한다.

## 크기

| 파일 | 1x | 2x | 4x | 8x |
| --- | ---: | ---: | ---: | ---: |
| `state-<키>.png` 16종 · `star-capital.png` | 16 | 32 | 64 | 128 |
| `imperial-residence.png` | 24 | 48 | 96 | — |
| `imperial-npc.png` | 16 | 32 | — | — |

배율마다 원화에서 따로 축소·픽셀 힌트한다(최근접 확대본이 아니다). 알파는 이진이다.
배지가 약 15–64 CSS px 로 그려지므로 런타임은 `CSS 크기 × DPR` 이상인 가장 작은 배율을
고르고, 그보다 작게 그릴 때만 축소한다. 16px 1x 는 별·눈송이·해골·소용돌이·동전·칼처럼
단순한 것은 읽히지만, 장면형(5·7·8·9·34·고립·포위·공사)은 실루엣 뭉치로만 보이므로
지도 배지만으로 의미를 외우게 하지 말고 선택 패널의 상태명과 툴팁을 함께 제공한다.
고립(자루+사슬)과 탈취(자루+동전)는 자루 몸통이 닮았다 — 사슬(회색)·동전(금색)으로
갈린다.

`status/<이름>.png` 평면 경로는 옛 이름(상태 코드 12종·수도 별·황제 2종)에 한해 1x 사본으로
남긴다. 휘하 신규 4종은 배율 폴더에만 있다.

검수 시트 `preview.png`: 열 = 아이콘, 1–4행 = 1x·2x·4x·8x 를 같은 128px 로 최근접
확대, 5행 = 실제 크기(1x·2x·4x) 지도색 바탕.
