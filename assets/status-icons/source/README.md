# 상태 아이콘 원화

`status-master-imagegen.png`는 OpenAI ImageGen의 이미지 편집 모드로 만든 4×4 픽셀아트
시트다. 1–12번 셀은 상태 코드 `1,2,3,4,5,6,7,8,9,32,34,43`, 13번 셀은 수도 별이며
나머지 셀은 비어 있다. 황제 거처 표식은 구 파비콘 원본을 복구한 뒤 별도 추가한다.

최종 프롬프트의 핵심 조건은 다음과 같다.

- 상업 게임 수준의 16비트 아이소메트릭 전략게임 픽셀아트
- 4×4 동일 셀, 투명 배경, 글자·라벨·구분선 없음
- 좌상단 광원, 어두운 갈흑색 외곽선, 3단 명암, 제한 팔레트
- 24×24 축소에서도 구분되는 강한 실루엣
- 9번은 황건·도적 세력과 겹치지 않는 민란: 부러진 관아 명패, 횃불, 농기구
- 황제 거처 칸은 복구 전까지 투명하게 유지
